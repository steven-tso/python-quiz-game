# 🐍 Python 猜謎大挑戰（60 秒限時互動遊戲）

一個**免安裝、單一 HTML 檔**的 Python 主題猜謎互動遊戲，適合課堂暖身、分組搶答與課後自學複習。

## ✨ 功能特色

- ⏱️ **60 秒限時挑戰**：全場倒數計時，最後 10 秒警示音與紅色閃爍，時間歸零立即結算，剩餘時間可折算加分。
- ❓ **每回 10 題**：從 35 題 Python 題庫中**隨機抽題**，選項順序也隨機打亂，每回挑戰都不重複。
- 🔊 **內建互動音效**：以 Web Audio API 即時合成，無任何外部音效檔（答對琶音、答錯低鳴、倒數警示、結算樂曲）。
- 🎆 **答題特效**：Canvas 彩帶火花、答錯卡片震動、正確/錯誤選項變色動畫、分數動畫。
- 📋 **完整結算成績單**：總分、評語、答對數、正確率、作答時間、最高連對，並**逐題列出你的答案、正確答案與觀念解析**，可直接當複習教材。

## 🕹 操作方式

| 操作 | 說明 |
|---|---|
| 開始 | 點擊「🚀 開始挑戰」或按 `Enter` |
| 作答 | 點擊選項，或按鍵盤 `1`～`4` |
| 跳過 | 點擊「⏭ 跳過此題」或按 `Esc`（計 0 分） |
| 再玩 | 結算頁「🔁 再挑戰一回」會重新隨機抽題 |

## 🚀 使用方式

1. 下載 `python猜謎互動遊戲.html`
2. 用瀏覽器（Chrome / Edge / Firefox / Safari）直接開啟即可遊玩
3. 課堂上可投影於大螢幕分組搶答，亦可上傳至任何靜態網站空間

## 🌐 線上遊玩（GitHub Pages）

本倉庫已可啟用 GitHub Pages：

1. 倉庫 **Settings → Pages**
2. **Source** 選擇 `Deploy from a branch`
3. **Branch** 選擇 `main`、資料夾選 `/ (root)`，按 Save
4. 約 1 分鐘後即可透過 `https://<你的帳號>.github.io/python-quiz-game/` 開啟

> 提示：可將首頁檔案改名為 `index.html`，網址就不必附檔名。

## 📚 題庫涵蓋範圍

Python 創始者與起源、基本語法與輸出、資料型別（list / dict / tuple / set）、運算子與優先順序、字串操作、迴圈與 `range()`、函式 `def`、類別 `class`、例外處理 `try...except`、型別轉換、f-string、`if __name__ == "__main__"`、套件管理 `pip`、`import this` 彩蛋等。

## 🛠 技術採用

- 原生 **HTML + CSS + JavaScript**，無框架、無建置流程、無 CDN 依賴
- 音效：Web Audio API
- 特效：Canvas 2D 粒子系統
- 響應式版面：支援桌機與平板
